# Математический аппарат

## 1. Формальная модель

### 1.1 Участники и роли

Пусть задано множество участников $U = \{u_0, u_1, \dots, u_{N-1}\}$, $N \ge 3$. Каждый участник в рамках одной цепочки имеет ровно одну роль: $D$ — донор, $R$ — реципиент, $M$ — монитор. В разных цепочках роли могут отличаться.

### 1.2 Цепочка

Цепочка $C_i = (D_i, R_i, M_i)$, где $D_i \neq \varnothing$, $R_i \neq \varnothing$, $M_i \neq \varnothing$. Обозначим $|D_i| = d_i$, $|R_i| = r_i$, $|M_i| = m_i$. Общее число цепочек — $K$; индексы $i \in \{0, \dots, K-1\}$.

### 1.3 Ограничение участия

Для каждой цепочки: $D_i \cap R_i = R_i \cap M_i = D_i \cap M_i = \varnothing$. Между различными цепочками пересечения допустимы.

### 1.4 Число валидных цепочек

Цепочка теряет валидность при $r_i = 0$ или $m_i = 0$. Число валидных цепочек:

$$S = \sum_{i=0}^{K-1} \chi_i, \qquad \chi_i = \begin{cases} 1, & r_i \ge 1 \text{ и } m_i \ge 1 \\ 0, & \text{иначе} \end{cases}$$

## 2. Вероятность случайного угадывания

Если сигнал состоит из $n$ независимых элементов, элемент $j$ принимает $k_j$ равновероятных значений:

$$P = \prod_{j=0}^{n-1} \frac{1}{k_j}$$

В частном случае $k_j = k$: $P = (1/k)^n$.

**Пример.** Сигнал «Розовая капуста правит Римом»: пространства 300 × 10 × 10 000, тогда $P = 1/30\,000\,000 \ll 1\%$.

## 3. Оптимальная организация участников

### 3.1 Матрица участия

Три матрицы $\mathbf{D}, \mathbf{R}, \mathbf{M} \in \{0,1\}^{N \times K}$: $D_{ji} = 1 \iff u_j \in D_i$, аналогично для $R$, $M$. Ограничение: $D_{ji} + R_{ji} + M_{ji} \leq 1$ для всех $j, i$. Степень участия: $\deg_R(j) = \sum_{i=0}^{K-1} R_{ji}$, аналогично для $D$, $M$.

### 3.2 Сбалансированная конфигурация

Конфигурация **сбалансирована**, если $\deg_D(j) = \deg_R(j) = \deg_M(j) = p$ для всех $j$. При $d_i = r_i = m_i = 1$: $K = Np$. При $p = 1$ — минимальная конфигурация: $K = N$.

### 3.3 Базовая циклическая конструкция ($t = 0$)

$$C_i = \bigl(\{u_i\},\; \{u_{(i+1)\bmod N}\},\; \{u_{(i+2)\bmod N}\}\bigr), \quad i = 0, \dots, N-1$$

Свойства: $K = N$, $p = 1$, $S_0 = N$. Каждое выбывание деактивирует ровно 2 цепочки. После $q$ выбываний: $S \geq N - 2q$.

### 3.4 Конструкция с избыточностью (робастность $t \geq 1$)

Требование: $r_i \geq t+1$ и $m_i \geq t+1$ для всех $i$. Минимум участников: $N_{\min} = 2t + 3$.

При $N$ кратном $(t+1)$, шаг $s = N/(t+1)$:

$$C_i = \Bigl(\{u_i\},\; \{u_{(i+1+ks)\bmod N} \mid k = 0,\dots,t\},\; \{u_{(i+2+ks)\bmod N} \mid k = 0,\dots,t\}\Bigr)$$

**Теорема.** Данная конструкция сохраняет $S = N$ при любых $t$ одновременных выбываниях.

### 3.5 Максимальная робастность и сводная таблица

$$t_{\max} = \left\lfloor \frac{N-3}{2} \right\rfloor$$

| $N$ | $t_{\max}$ | $K$ | $r_i = m_i$ | $S$ при $q$ выбываниях |
|:---:|:----------:|:---:|:-----------:|:----------------------|
| 3 | 0 | 3 | 1 | $S \geq 3 - 2q$ |
| 5 | 1 | 5 | 2 | $S = 5$ при $q \leq 1$ |
| 7 | 2 | 7 | 3 | $S = 7$ при $q \leq 2$ |
| 9 | 3 | 9 | 4 | $S = 9$ при $q \leq 3$ |
| $N$ | $\lfloor(N-3)/2\rfloor$ | $N$ | $t_{\max}+1$ | $S = N$ при $q \leq t_{\max}$ |
