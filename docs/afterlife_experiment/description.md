# Эксперимент загробный

Эксперимент основан на принципе слепого метода и направлен на минимизацию субъективных влияний участников. Его исходная гипотеза допускает возможность того, что после биологической смерти человек может сохранять способность к передаче интерпретируемых сигналов живым людям.

Под **сигналом** понимается заранее сформулированная и зафиксированная информация, потенциально доступная для интерпретации Реципиентом.

## Роли участников

**Донор** — при жизни формирует и письменно фиксирует в анкете набор сигналов, которые могут быть переданы после его биологической смерти Реципиенту. Анкета заполняется заранее и недоступна Реципиенту.

**Реципиент** — не имея доступа к анкете Донора, фиксирует предполагаемые сигналы и передаёт их Монитору для проверки.

**Монитор** — имеет доступ к анкете Донора и проверяет предположения Реципиента. На каждый запрос Монитор отвечает исключительно «да» или «нет».

## Структура взаимодействия

Базовой единицей является цепочка: **Донор → Реципиент → Монитор**. Цепочка считается **валидной**, пока в ней присутствует хотя бы один живой Реципиент и хотя бы один живой Монитор. Роль Донора на валидность не влияет — его анкета остаётся доступной после смерти. Цепочка считается **активной**, если из неё выбыл хотя бы один Донор (то есть эксперимент по ней уже идёт).

## Условия завершения

Эксперимент завершается при **позитивном результате** — Монитор подтверждает точное совпадение сигнала — или при **прекращении без результата**: компрометация данных всех Доноров, либо исчезновение Реципиентов или Мониторов во всех цепочках.

## Шкала совпадений

- **0** — нет совпадения
- **1** — частичное совпадение (для анализа, но не как результат)
- **2** — полное совпадение (единственное основание для позитивного результата)

## Правила

Донорам и Мониторам строго запрещено передавать содержание сигналов Реципиентам. Реципиент должен проверять у Монитора даже размытые предположения. Анкеты хранятся с обеспечением недоступности для Реципиентов.
